Introduction

HTML is the standard language used to structure content on the web.

It uses elements to describe headings, paragraphs, links, images, forms, and more.

<h1>Hello World</h1>
  • HTML gives structure to a webpage.
  • CSS styles the webpage.
HTML Elements

HTML elements are made of opening tags, content, and closing tags.

Some elements, like images and inputs, are void elements and do not need closing tags.

<p>This is a paragraph.</p>
  • Block elements start on a new line.
  • Inline elements stay within the flow of text.
Forms

Forms collect user input and send it to a server or process it with JavaScript.

Labels should be connected to inputs for better accessibility.

<input type="email" id="email">
  • Use labels for inputs.
Tables

Tables display data in rows and columns.

Use table headers to describe the meaning of each column.

<table><tr><td>Data</td></tr></table>
  • Use captions when helpful.
Accessibility

Accessibility ensures that websites can be used by as many people as possible.

Good HTML structure helps screen readers and keyboard users navigate content.

<img src="cat.jpg" alt="Orange cat lying down">
  • Use descriptive alt text.
